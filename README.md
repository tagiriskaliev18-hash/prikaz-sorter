# ПриказСорт

Простой и конфиденциальный веб-сортировщик документов-приказов: загрузите несколько файлов-приказов, и приложение мгновенно переименует их по номеру приказа и ФИО сотрудника, указанного внутри.

## Возможности

- **100% локально в браузере** — файлы никуда не отправляются, все вычисления происходят на вашем устройстве.
- **Поддержка форматов**: `.docx`, `.pdf` (текстовые и сканы с OCR), `.rtf`, `.odt`, `.txt`, `.doc`, а также изображения сканов (`.png`, `.jpg`, `.webp`).
- **Умное извлечение реквизитов**:
  - Находит номер приказа (`ПРИКАЗ № 124-к`, `БҰЙРЫҚ № 87-ж/қ`, многострочные шапки-таблицы) и отсеивает ИИН, БИН, ИНН, табельные номера и номера договоров.
  - Выбирает ФИО сотрудника (субъекта приказа), исключая директора-подписанта в конце документа.
  - Автоматически приводит ФИО из косвенных падежей (*Иванова Ивана Ивановича* → *Иванов Иван Иванович*), сохраняя несклоняемые фамилии и казахские патронимы.
- **Гибкое переименование**: готовые пресеты и свой шаблон (`{number}`, `{fio}`, `{date}`, `{orig}`), сокращение `Фамилия И.О.`, санитизация символов под Windows/macOS, авторазрешение дубликатов `(2)`.
- **Быстрая выгрузка**: скачивание по одному, одним `.zip`-архивом или прямо в выбранную папку (в Chrome/Edge).

## Разработка

```bash
npm install
npm test
npm run dev
npm run build
```
